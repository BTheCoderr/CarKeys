# Contributing to CarKeys

CarKeys is a kid-first music-and-driving game concept.

The product rule is simple: **fun first, educational second**. Musical learning should emerge from play rather than feeling like a lesson with a car skin.

Before proposing a change, make sure it improves the playable loop, timing/feedback, kid-friendly clarity, accessibility, or progression. Avoid expanding the concept before the first vertical slice feels coherent.

When implementation code is added, include reproducible run/build instructions and tests for timing-critical game logic where practical.
