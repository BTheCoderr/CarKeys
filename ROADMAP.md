# CarKeys Roadmap

This roadmap describes direction, not guaranteed dates.

## Current stage

- product/game concept defined
- core car + music interaction direction established
- kid-first visual and learning principles documented
- Twin Mode accessibility direction defined

## Next milestone

Build one small vertical slice that proves:

- piano/keyboard input maps clearly to vehicle action
- rhythm/timing changes what happens on screen
- feedback feels fluid rather than instructional
- one short story/challenge loop makes sense to a child
- Twin Mode reduces choices without removing the fun

## After the vertical slice

- progression and short level structure
- visual/audio polish
- mobile-friendly controls
- save/progress model
- broader accessibility and parent-facing settings

## Product boundary

Do not turn CarKeys into a traditional music lesson app. The game has to work as a game first.
